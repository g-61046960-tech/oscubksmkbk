01

Sediakan sambungan Google Drive

Buka Google Cloud Console menggunakan akaun cikgu. Cipta atau pilih projek khusus, contohnya OSC UBK SMKBK.

  1. Pilih APIs & Services → Library. Cari Google Drive API, kemudian pilih Enable.
  2. Pilih APIs & Services → Credentials → Create credentials → API key. Salin API key yang dihasilkan.
  3. Buka tetapan key tersebut. Di API restrictions, pilih Restrict key → Google Drive API, kemudian simpan. Ini bukan Gemini API key atau kata laluan Google.

Key digunakan oleh pelayan Worker, bukan oleh pelayar pengunjung. Jangan tetapkan sekatan jenis HTTP referrers / Websites kepada domain portal untuk key pelayan ini. Hadkan API kepada Google Drive API dan simpan nilainya sebagai Secret pada langkah 3. Jangan masukkan key dalam HTML, repositori awam, tangkap layar atau mesej sembang.

Portal menggunakan akses awam tanpa log masuk pemilik. Fail Restricted atau terhad kepada domain tidak akan dibuka menggunakan API key ini. Jangan tukar rekod kaunseling atau data peribadi murid kepada perkongsian awam semata-mata untuk memaparkannya.

02

Pasang kod Worker

Buka dashboard Cloudflare, kemudian Workers & Pages. Untuk mencuba tanpa menimpa laman sedia ada, cipta Worker baharu melalui Create application → Create Worker atau pilihan Hello World yang dipaparkan, kemudian Deploy.

Buka Worker itu dan pilih Edit code. Padam kod contoh, kemudian tampal seluruh kandungan worker.js menggunakan butang di bawah. Klik Deploy. Jika mengemas kini Worker sedia ada, simpan salinan kod atau versi lama terlebih dahulu.

Lihat kod untuk salin secara manual

Semua logo dan gambar kaunselor sudah terkandung dalam fail Worker. Tidak perlu memuat naik gambar berasingan. Jangan muat naik ZIP ini ke Pages sebagai laman statik; gunakan kod worker.js dalam editor Worker. Fail index-pratonton.html hanya untuk menyemak reka bentuk dan beberapa folder contoh yang telah dibaca, bukan sambungan langsung.

03

Masukkan Secret di Cloudflare

  1. Dalam Worker yang sama, pilih Settings → Variables and Secrets → Add.
  2. Pilih jenis Secret. Nama tepat: DRIVE_API_KEY.
  3. Masukkan API key daripada langkah 1 pada ruangan Value, kemudian klik Deploy.

Buka alamat workers.dev yang diberikan oleh Cloudflare. Apabila sambungan berjaya, status portal bertukar kepada Diselaraskan. Tiada URL laman baharu ditetapkan oleh pakej ini sehingga cikgu menerbitkannya.

04

Aktifkan paparan sahaja pada fail asal

Langkah ini diperlukan sebelum kandungan dokumen dibuka dalam portal. Dalam Google Drive pada komputer, pilih fail → Share → Settings. Nyahaktifkan hak download, copy dan print untuk Viewers and commenters melalui pilihan yang tersedia pada akaun cikgu, kemudian simpan.

Portal menyemak sekatan fail sebelum membuka pemapar. Jika sekatan belum aktif atau Google tidak mengesahkannya, portal memaparkan “Paparan sahaja belum diaktifkan” dan tidak memuatkan dokumen. Nama fail tetap muncul dalam senarai jika fail itu boleh disenaraikan secara awam.

Tetapan ini perlu disemak pada setiap fail, termasuk fail baharu; jangan anggap sekatan pada satu fail diwarisi oleh semua kandungan folder My Drive. Sekatan berasaskan Shared Drive atau pentadbir juga dibaca jika dilaporkan oleh Google Drive API.

Had perlindungan: Tiada butang muat turun, salin atau cetak disediakan oleh portal. Pemapar disekat daripada membuka tab baharu, muat turun melalui iframe dan dialog cetak; helaian cetak portal juga menyembunyikan dokumen. Namun, laman web tidak boleh menjamin pencegahan tangkap layar, foto skrin atau penyalinan oleh pengguna teknikal. CSS dan sekatan papan kekunci bukan DRM. Pengguna yang mempunyai akses pemilik/editor mungkin mempunyai hak tambahan di Google Drive.

Uji paparan menggunakan tetingkap peribadi/incognito sebagai pengunjung, bukan hanya ketika log masuk sebagai pemilik fail. Semak bahawa fail boleh dibaca dan pilihan muat turun, cetak serta salin Google juga tidak tersedia. Jika jenis fail, tetapan sekolah, kuki atau pelayar tidak menyokong pemapar Google, portal tidak menyediakan pautan muat turun alternatif.

05

Cara kemas kini berlaku

Senarai bahan dibaca semula apabila folder dibuka, apabila butang segarkan ditekan, apabila pelayar kembali aktif, dan setiap 60 saat semasa halaman kelihatan. Tiada senarai dokumen tetap digunakan pada Worker. Penambahan, pertukaran nama dan pemadaman bahan akan dikesan pada semakan seterusnya.

Jika dokumen yang sedang dibaca berubah, pemapar dimuat semula selepas perubahan modifiedTime dikesan. Jika fail dipadam, dipindah keluar daripada direktori atau akses tidak lagi dibenarkan, pemapar ditutup atau digantikan dengan mesej akses. Perubahan bergantung pada masa pemprosesan Google Drive dan sambungan Internet, bukan notifikasi masa nyata serta-merta.

Fail yang baru ditambah perlu mempunyai akses tontonan yang sesuai dan sekatan langkah 4. Bahan lama yang gagal disegarkan ditandai sebagai paparan terakhir, bukan dilabel sebagai terkini. Carian bahan mencari dalam folder semasa; carian menu mencari bahagian utama.

Semakan sebelum dikongsi

  1. Logo dan dua gambar kaunselor muncul pada laman utama. Gambar kaunselor tidak muncul apabila masuk ke folder.
  2. Buka 1. UTAMA, kemudian b. Visi dan misi. Senarai dan pemapar mesti kekal di dalam portal.
  3. Buka 2. PENGURUSAN & PENTADBIRAN → Laporan Harian SePKM. Pautan menuju terus ke https://www.sepkm.com/e/login/ dalam tab yang sama.
  4. Uji fail yang sudah disekat untuk pembaca. Kemudian cuba satu fail tanpa sekatan; portal mesti menolak pemapar fail kedua itu.
  5. Tambah atau tukar nama bahan ujian di Drive. Tekan segarkan atau tunggu semakan 60 saat. Selepas selesai, buang bahan ujian.

Jangan gunakan maklumat peribadi murid untuk ujian. Kod menggunakan API baca sahaja dan tidak menyediakan fungsi mengubah kandungan Drive.
