UBK SMK Buluh Kasap

Versi Kepimpinan Murid. Laman, gambar, logo dan sambungan folder disatukan dalam satu kod Worker.

Ini halaman pemasangan, bukan laman UBK untuk pelawat.
Jangan seret fail ini atau ZIP ke “Upload static files”. Pakej ini dipasang melalui Edit code pada Worker baharu.

1Salin kod lengkap

Klik butang ini. Kod laman dan sambungan folder akan disalin bersama.

Paparkan kod untuk salinan manual

Klik dalam kotak, tekan Ctrl+A kemudian Ctrl+C. Pada Mac, gunakan ⌘A kemudian ⌘C.

2Cipta Worker baharu

  1. Dalam Cloudflare, buka Workers & Pages → Create application.
  2. Pilih Start with Hello World! atau templat Hello World. Bukan Upload static files.
  3. Namakan Worker, contohnya osc-ubk-kepimpinan, kemudian pilih Deploy. Gunakan nama lain jika nama ini sudah digunakan.

Laman lama tidak perlu dipadam. Worker baharu ini tidak memerlukan ASSETS, KV, pangkalan data, atau tetapan Pages.

3Tampal dan terbitkan

  1. Buka Worker yang baru dicipta dan pilih Edit code.
  2. Klik fail kod utama yang mengandungi “Hello World”, padam semua kod asal, kemudian tampal semua kod daripada langkah 1. Jangan tampal di bahagian aset.
  3. Pilih Deploy untuk menerbitkan perubahan, bukan sekadar menyimpan draf.
  4. Buka alamat Worker berakhir .workers.dev. Pilih PRS → Carta Organisasi, kemudian cuba kembali melalui Folder sebelumnya.

Semakan selepas penerbitan

Folder dan subfolder dipaparkan sebagai butang dalam laman. PDF, imej, slaid, audio dan video yang disokong dibuka dalam ruang pratonton. Tiada tab Google Drive dibuka oleh navigasi portal.

Tambah atau sunting fail di folder asal seperti biasa. Laman meminta semula senarai folder setiap 60 saat apabila Auto hidup, tab aktif dan ruangan kandungan kelihatan. Penyegaran dijeda sewaktu pratonton dibuka. Tekan Muat semula untuk meminta paparan baharu.

Semak akses bahan sebelum diterbitkan. Penyambung ini membaca senarai folder yang boleh dicapai secara awam sahaja; ia tidak log masuk ke akaun Google cikgu. Jangan jadikan rekod sulit murid sebagai umum untuk mengatasi mesej akses ditolak.

Sesetengah format atau tetapan pelayar tidak menyokong pratonton. Dalam keadaan itu, laman memaparkan makluman, bukan tab luar. Sambungan ini menggunakan paparan HTML awam Google, bukan API rasmi. Ia mungkin memerlukan penyelenggaraan jika Google menukar struktur atau mengehadkan akses.

Kod dan navigasi diuji secara tempatan dengan respons simulasi. Akses Google Drive sebenar dari Worker cikgu mesti disahkan selepas Deploy. Tiada laman diterbitkan dan tiada kebenaran perkongsian diubah oleh pakej ini sebelum cikgu memasangnya.
